Connect your YouTube

This needs a one-time Google setup so uploads go to your channel. Connecting grants upload access and read access to your channel’s existing uploads for duplicate checks.

  1. In Google Cloud, create a project and enable YouTube Data API v3.

  2. Configure Google Auth Platform. If the app is in Testing, add your Google account as a test user.

  3. Create an OAuth client with application type Desktop app, then download its JSON file.

Credentials and your authorization stay in this app's local .data folder. Keep that folder private.
